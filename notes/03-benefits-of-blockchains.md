# The Permissionless Power of Blockchain
Source: Updraft – Blockchain Basics, lesson 3

## What it is
The 5 properties that make blockchain different from banks:
permissionless, credibly neutral, decentralized, transparent, immutable.

## Example
```
BANK (permissioned)                 BLOCKCHAIN (permissionless)

You ─ask permission─▶ Bank          You ──────────▶ Network
       ❌ can deny / freeze / block        ✅ no one can deny or block

One central server → one point of failure
Thousands of nodes → no single point to shut down
```

```
Property        Bank                      Blockchain
Access          needs ID, address, OK     anyone with internet
Neutrality      can discriminate          code treats everyone equally
Control         one company / government  thousands of nodes
Visibility      closed doors              public, anyone can audit
Rules           change without warning    open-source, can't be altered
```

## Key words
- Permissionless = no one's approval needed to use the network
- Credibly neutral = rules are open code, so the network can't play favorites
- Decentralized = no single owner or point of failure
- Transparent = all transactions are public and auditable
- Immutable = once recorded, can't be changed or deleted
